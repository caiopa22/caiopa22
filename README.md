## 🚀 Featured projects

### 🌱 [EarthSense](https://github.com/caiopa22/earth-sense)
Capstone project (4 students): low-cost soil moisture monitoring for precision agriculture, combining **IoT, machine learning and a web dashboard**. An ESP32 with five capacitive sensors sends readings in batches to a Node.js/Express API backed by Supabase (PostgreSQL), and a React dashboard shows history and charts. A Ridge regression model trained with scikit-learn on the project's own data forecasts each sensor's moisture 30 minutes ahead, with inference running in TypeScript.

`ESP32` `Node.js` `TypeScript` `React` `Supabase` `Python` `scikit-learn`
